# Kepler

An Omarchy extra theme: void indigo, brass copper, parchment light.

Omarchy ships palettes and wallpapers as **themes**, not shell plugins. Install this repo with `omarchy theme install`.

## Install

```bash
omarchy theme install https://github.com/gerworkmail-cpu/omarchy-kepler-theme.git
```

That clones into `~/.config/omarchy/themes/kepler/` and applies it.

## After install

```bash
omarchy theme set kepler
omarchy theme bg next
omarchy theme bg-switcher
```

## Palette

| Role | Hex |
|------|-----|
| Background | `#14121c` |
| Foreground | `#ece4d4` |
| Accent | `#e0a15a` |
| Selection | `#2b2438` |
| Red | `#e07a7e` |
| Green | `#8fba8a` |
| Cyan | `#7eb8c4` |
| Blue | `#7a96c8` |

Body text contrast is about 14.7:1. The brass accent is about 8.3:1 on the background.

## Backgrounds

| File | Scene |
|------|--------|
| `backgrounds/1-observatory.webp` | Hillside observatory under the Milky Way |
| `backgrounds/2-telescope.webp` | Brass telescope on a night ridge |
| `backgrounds/3-nebula.webp` | Copper and teal dust clouds |
| `backgrounds/omarchy.webp` | Kepler-tinted Omarchy wordmark |

Add extra wallpapers for this theme in `~/.config/omarchy/backgrounds/kepler/` so they survive theme updates.

## Icons

`Yaru-yellow`, to sit next to the copper accent.
